# ForLibrary

Este é um projeto Android desenvolvido como parte de um sistema de gerenciamento de biblioteca ou consulta de acervo.

## 📋 Descrição

O **ForLibrary** é um aplicativo Android nativo que visa facilitar o acesso e a organização de informações bibliográficas. Atualmente, o projeto encontra-se em sua fase inicial, apresentando uma estrutura base sólida para expansão futura de funcionalidades como listagem de livros, busca e detalhes de obras.

## 🚀 Como Executar o Projeto

Para rodar este projeto localmente, siga os passos abaixo:

### Pré-requisitos

*   **Android Studio** (versão Ladybug ou superior recomendada)
*   **JDK 17** ou superior
*   **Android SDK** configurado
*   Um dispositivo físico Android com o Modo Depurador ativado ou um Emulador configurado no Android Studio.

### Passos para Instalação

1.  **Clonar o Repositório:**
    ```bash
    git clone https://github.com/seu-usuario/ForLibrary.git
    ```
    *(Substitua pela URL real se estiver em um repositório remoto)*

2.  **Abrir no Android Studio:**
    *   Abra o Android Studio.
    *   Selecione **File > Open**.
    *   Navegue até a pasta onde você clonou o projeto e selecione-a.

3.  **Sincronizar o Gradle:**
    *   O Android Studio deve iniciar a sincronização automaticamente. Caso contrário, clique no ícone de "Elephant" (Sync Project with Gradle Files) na barra de ferramentas superior.

4.  **Executar o Aplicativo:**
    *   Selecione o seu dispositivo/emulador na barra de ferramentas.
    *   Clique no botão **Run** (ícone de play verde) ou use o atalho `Shift + F10`.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Kotlin
*   **Interface:** XML (View System) com ConstraintLayout
*   **Build System:** Gradle (Kotlin Script - `.kts`)
*   **Compatibilidade:** Android 9.0 (API 28) ou superior

## 📂 Estrutura do Projeto

*   `app/src/main/java`: Contém o código-fonte Kotlin.
*   `app/src/main/res`: Contém os recursos do app (layouts, strings, ícones).
*   `app/src/main/AndroidManifest.xml`: Arquivo de configuração essencial do Android.
