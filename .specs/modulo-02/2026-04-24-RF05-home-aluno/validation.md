# Validação: RF05 - Tela Home do Aluno

## Checklist de Requisitos
- [ ] O cabeçalho exibe corretamente a foto de perfil, a saudação com o nome do usuário e os pontos de gamificação?
- [ ] O clique nos pontos redireciona corretamente para a tela Meus Pontos (RF21)?
- [ ] O clique no símbolo de sino redireciona para a tela de notificações?
- [ ] O card "Continue Lendo" exibe capa, título, autor, capítulo atual e barra de progresso com porcentagem?
- [ ] O clique no card "Continue Lendo" abre a Tela de Leitor Digital (RF10)?
- [ ] O carrossel "Destaques do Acervo" exibe uma lista horizontal com capa, título e autor dos livros?
- [ ] O clique no texto "ver todos" redireciona para a tela de Acervo Digital (RF06)?
- [ ] Os livros marcados como salvos exibem o ícone de bookmark no canto superior direito?
- [ ] O card "LIVROS LIDOS" exibe a quantidade correta baseada no histórico do usuário?
- [ ] O card "TEMPO TOTAL" exibe as horas totais de leitura do usuário?
- [ ] O clique no botão do robô aciona o PopUp do Chat Bot (RF41) corretamente?
- [ ] A Bottom Navigation Bar fixa está presente e funcional na base da tela?
